# Native Sparse Attention (NSA)

**日期**: 2025 年 2 月 16 日  
**arXiv**: https://arxiv.org/abs/2502.11089  
**HuggingFace**: https://huggingface.co/deepseek-ai  
**备注**: 官方未发布独立仓库；社区实现见 lucidrains/native-sparse-attention-pytorch、tilde-research/nsa-release

## 概述
Native Sparse Attention（NSA）是 DeepSeek-AI 等于 2025 年 2 月 16 日发布的论文，arXiv:2502.11089。论文针对长文本建模中标准自注意力 O(N²) 计算成本问题，提出可原生训练的稀疏注意力机制。NSA 采用动态分层稀疏策略：粗粒度 token 压缩 + 细粒度 token 选择 + 滑动窗口局部上下文，兼顾全局感知与局部精度。核心创新在于算术强度均衡的算法设计与硬件对齐优化，实现预训练端到端训练不降性能；同时在 64k 长度序列上，解码、前向与反向传播均实现显著加速。该技术已被应用于 DeepSeek-V4 等后续模型。

## 论文要点
- 动机：标准注意力在长序列下占比 70-80% 延迟，多数稀疏方法仅推理阶段使用、难达理论加速，且非可训练导致性能损失。
- 核心设计：三分支分层稀疏——压缩注意力（粗粒度压缩，兼顾全局）、选择注意力（细粒度 token 选择，保留重要块）、滑动窗口（局部上下文）。
- 硬件对齐：块式稀疏、算术强度均衡、Tensor Core 利用、内存访问优化，Triton 实现，覆盖预填充与解码全阶段。
- 可原生训练：支持端到端反向传播，27B 模型在 260B token 预训练上，NSA 在通用基准、长文本、指令推理上达到或超过全注意力基线。
- 效率：64k 序列下解码、前向、反向均显著提速，越长序列加速比越高，验证全生命周期效率。

## 技术细节
- 分层稀疏框架：输入序列按时间块组织，对每个查询执行三路径注意力：压缩路径对键值做粗粒度聚合，保留全局上下文；选择路径基于查询相关性动态挑选重要 token 块，实现细粒度保留；滑动窗口提供局部邻域精确建模。
- 算法设计：块级稀疏建模保证算术强度均衡；压缩与选择协同，避免仅粗粒度丢失细节或仅细粒度成本过高。
- 内核设计：为现代 GPU 设计专用 Triton 内核，优化 Tensor Core 利用率与内存访问模式，支持 MQA/GQA，prefill 与 decode 均加速；反向传播高效实现，避免离散选择导致梯度断裂。
- 训练友好：避免不可微操作，采用可训练的压缩与选择机制，实现稳定端到端预训练，减少长序列训练计算成本。

## 应用场景
- 超长上下文 LLM：长文档理解、代码库级生成、多轮对话、复杂推理等需 64k+ 序列的场景，降低延迟与显存占用。
- 训练阶段加速：长序列预训练、长文本微调、RLHF 等需要高效反向传播的任务，降低训练成本。
- 边缘与资源受限部署：通过稀疏化在有限 GPU/内存下运行大模型推理，提升吞吐。
- 研究与系统优化：为稀疏注意力提供可训练基线，推动硬件-算法协同设计。

## 相关研究
- 稀疏注意力：固定稀疏模式、动态 token pruning、查询感知选择等，如 H2O、MInference、Quest、ClusterKV、MagicPIG、HashAttention。
- KV 缓存优化：KV-cache eviction、blockwise 选择等，如 Mistral、GQA/MQA。
- 硬件感知注意力：FlashAttention、Triton 内核、算术强度优化。
- 长上下文建模：Transformer 扩展、线性注意力、RWKV、RetNet 等。

## 笔记
- NSA 的关键是从“推理后稀疏”转向“原生可训练稀疏”，解决了后稀疏的性能损失与训练不可用问题。
- 分层设计兼顾效率与表达：压缩保证全局、选择保证关键细节、窗口保证局部。
- 硬件对齐是稀疏方法落地的核心，算术强度与内存访问模式决定实际加速。
- 未来可探索自适应稀疏率、跨层稀疏协同、与其他压缩技术（如量化、MoE）结合。
